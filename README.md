# AmbedkarGPT-Intern-Task
A simple command-line RAG system using LangChain, ChromaDB, and Ollama Mistral to answer questions from Dr. Ambedkar’s speech.
src/
│── cli.py                # Manual testing
│── main.py               # FastAPI production server
│── retriever.py          # Hybrid RAG retrieval
│── vectordb.py           # Chroma DB build/load
│── llm.py                # Ollama/Mistral client
│── rag_pipeline.py       # Complete RAG pipeline
│── embedding.py
│── document_processor.py
│── logger.py
│── exception.py
│── config.py
